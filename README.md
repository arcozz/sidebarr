# Sidebar Tidy

- `sidebar_tidy.uc.js` : déplace le VPN et les Réglages dans `#zen-sidebar-foot-buttons` (ils y restent même quand le bouton Téléchargements apparaît), et force l'URL en domaine seul quand la barre n'est pas active.
- `chrome.css` : masque Traduction, atténue les boutons, roue crantée, VPN en icône seule, barre d'adresse fine et arrondie.
- Debug : coche « Debug » dans les réglages du mod puis ouvre la Console (Ctrl+Shift+J).
